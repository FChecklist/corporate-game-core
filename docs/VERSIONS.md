# Version history of the core (0.1.0 to 0.7.0) and what each site must re-vendor
Re-vendor with `bun tools/vendor.ts <repo> --expect <version>`; the copy lands in `vendor/game-core/`. A site can jump straight to the latest version; the table says who is affected by each step.

| Version | Added | Who re-vendors |
|---|---|---|
| 0.1.0 | Engine, manifests, roles/modes/pause/flow/copy/retention, UI and wording, rules modules for Bingo, Tic Tac Toe, Snakes, Luck, reference Lucky Draw, Tambola Auto planner, rules books, vendor script with relative imports, entry points | all |
| 0.2.0 | People step rows "Add a Host" (Organizer only, max 5, own key approved later by the Organizer) and "Add a Co-host"; change list shows the role only (`core/people.ts`, `flow.ts`) | all five game sites (every People step) |
| 0.3.0 | Reaction pack: 52 text-only reactions, `reactions.ts` and `reactions.css`, demo page | all games that show reactions |
| 0.4.0 | Merge: Snakes simultaneous race and owner board (one shared 100-square board, special squares, reward = 2 throws); Tic Tac Toe owner rules (random pairing with a bye, 3-game matches, clocks, tie-breakers) | site-snakes, site-tictactoe |
| 0.5.0 | Merge: Snakes 8-minute rule; Luck owner rules (module reworked, `LUCK_RULES_BOOK.md`) | site-snakes, site-luck |
| 0.6.0 | Reaction scheduler: 2.2 s, corner strip, one at a time, 15 s gap, 15 per 10 minutes, personal vs shared, Organizer off; `createReactions(...)` replaces the old `react(id)` | every game that uses reactions |
| 0.7.0 | Merge: Tic Tac Toe stages (module and `TICTACTOE_RULES_BOOK.md` reworked) | site-tictactoe |

| 0.8.0 | Reaction pack redrawn as original work and set to exactly 50 phrases (4 words at most, everyday English); 8 own shapes, 8 colour pairs, own lettering; ids now follow the phrase (e.g. `hello`, `bam`, `aaah_bitten`, `champion`; high priority = `champion`, `bullseye`, `poof_gone`); a reaction may serve several events (`events`); `docs/REACTIONS_ORIGINAL.md` | every game that uses reactions |

| 0.8.1 | Manifests: Tic Tac Toe, Snakes and Luck list five prize places (1st to 5th), as their books say; Tic Tac Toe `markFor(side, gameIndex, bHasX?)` for the X/O alternation (book rule 7) | site-tictactoe, site-snakes, site-luck |

| 0.9.0 | Merge: Tic Tac Toe slot rules 3a-3e (three 100 s slots per stage, same pairing on every phone, tie order by sha256) and `packages/tictactoe/src/stages.ts` (`clockAt`, `pairSlot`, `settleStages`, `viewFor`) | site-tictactoe (needed); the others need nothing new from this step |
| 0.9.1 | Tic Tac Toe pairing: no repeat opponent with 4 or more free players (`unrepeat`, in `pairFree` and `pairSlot`); sit-out chosen among players without a bye this stage; simulation harness `tools/sim` | site-tictactoe |
| 0.9.2 | Tic Tac Toe rule 6: the sit-out goes first to a free player without one this stage; if everybody had one the lowest-ranked sits out again with NO point; the point is given at most once per player per stage (`applyBye`, `settleStages`); sim harness checks exactly this | site-tictactoe |
| 0.9.3 | Tic Tac Toe `settleStages`: disagreeing results for the same pair and slot count as a draw, independent of arrival order (book rule 3d) | site-tictactoe |
| 0.9.4 | Merge snakes-fixes: reward gives 2 extra throws at once (window opens straight away), id tie-break in `raceOrder`, paused state for reactions and game time, cap 2000 helper, single retention line (`wording`) | site-snakes (needed); site-tictactoe, site-luckydraw, site-bingo (shared `ui`, `wording` and `core` changes) |
| 0.9.5 | Wording: no "erase" anywhere; "auto-deleted" when the system deletes by timer, "deleted" when a person deletes. Retention names renamed `AUTO_DELETE_AFTER_MS`, `autoDeleteDue`, `AUTO_DELETED` (were `ERASE_AFTER_MS`, `eraseDue`, `ERASED`); the wording guard and `tools/conformance.ts` reject "erase" | every site (rename in code that uses the retention constants; replace "erase" in own pages, mails, helpdesk, legal text) |
| 0.9.6 | Wording: data and privacy sentences in third person, calm and short (`ID_ONLY_LINE`, `NAME_MOBILE_LINE`, `AUTO_DELETE_LINE`, `DATA_SENTENCES`); `dataTextOk` rejects we/our/us and harsh or legal-sounding words; conformance checks it | every site (use these sentences on screens, mails, helpdesk and Terms; no first person in data text) |
| 0.9.7 | Wording: data sentences no longer mention a name or a mobile number (only "participant details" / "participant data"); `NAME_MOBILE_LINE` replaced by `DETAILS_LINE`; `ID_ONLY_LINE` is just "A game can be played with only an employee ID or an e-mail."; the data guard rejects name, mobile, phone and number words | every site that used `NAME_MOBILE_LINE` or the 0.9.6 `ID_ONLY_LINE` text |
| 0.9.8 | Funnel-event helper (`makeReporter`, 13 events, first-party, no personal details, Global Privacy Control respected) and `NAVIGATION_LINE`; ONE common Privacy / Terms / Cookies / Grievance text in `wording` (`LEGAL`) with a shared renderer (`renderLegal`, `renderRules`) and a drift check (`tools/drift.ts`); only a game's rules differ | every game site and home: report funnel events, show the legal pages through `renderLegal`, delete own copies (run `bun tools/drift.ts <repo>`) |
| 0.9.9 | Test tooling only, no product change: `tools/journey/` journey smoke model and `docs/JOURNEY_MODEL.md` (catalog of 7.2 trillion journeys, invariants, seeded shardable generator) | nobody has to re-vendor |
| 0.9.10 | Test tooling only: journey run is now streaming and resumable (exact index ranges, budget, checkpoint, `--resume`, dry-run plan, `tools/journey/aggregate.ts`) | nobody has to re-vendor |

Re-vendor summary for 0.9.0 (a site may jump straight to it): **Snakes** (simultaneous race, owner board, 8-minute rule, five places), **Tic Tac Toe** (owner rules, stages, slots, `markFor`, five places), **Luck** (owner rules, five places), **Lucky Draw** (`packages/luckydraw`, `registerMany`), **Bingo** (settle from log, fate, late joiners, rounds), **master console** (People step Host/Co-host rows, Reaction pack 50 phrases, version check). All sites also get the People rows (0.2.0) and the Reaction scheduler (0.6.0 to 0.8.0).

Also in 0.1.x to 0.2.0, outside the numbered steps: Bingo aligned to live settle (site-bingo), Lucky Draw module `packages/luckydraw` with `registerMany` (site-luckydraw), `tools/load.ts` (no site action).
