- R2: press/gap/reveal seconds

- R5: each tie-break step, fate via node:crypto, 300-seed never-tied
- R6: top five, You won, prize positions (module and manifest)
- R7: min 2, cap 2000, 2000-player run, pause, start modes
- R8: reactions
- TIME: 120 s, 20 s per round, 440 s, 430 s, 7:00-8:00, 10:00, pause adds time
